使用帮助

如何记录一次冲动？

进入“记录”，选择金钱、食物或时间，再选择内置道具或创建自选道具。填写数值后，选择“我忍住了”“先放进冷静箱”或“我还是做了”。

冷静箱为什么没有提醒？

请前往 iPhone 的“设置 → 通知 → 忍了么”，确认“允许通知”已开启。低电量模式、专注模式或系统通知摘要可能影响提醒出现时间。

数据保存在哪里？

当前版本的记录、目标和自选图片都保存在设备本地，不会上传到服务器。删除 App 可能同时删除本地数据。

反馈问题

请前往 GitHub 提交问题，并附上设备型号、iOS 版本、问题发生步骤和截图。请勿在公开反馈中包含真实姓名、联系方式或其他敏感信息。
